# sjs

## 월배당 현금흐름 (`index.html`)

커버드콜·배당 ETF 보유 종목을 입력하면 아래를 바로 계산하는 한 페이지짜리 도구입니다.

- 월 예상 분배금 (세전 / 세후 실수령)
- 하락장 시나리오: 기초지수가 N% 빠지면 월 실수령이 얼마로 줄어드는지
- 세금 한도: 일반계좌 금융소득 종합과세 기준(연 2,000만원), ISA 비과세 한도 대비 현황

`index.html`을 브라우저로 열면 바로 동작합니다. 입력값은 그 브라우저에만 저장됩니다.

> 계산은 단순 추정입니다. 실제 분배금은 매달 달라지고, 세율·한도는 제도 변경이 있을 수 있습니다.

## 평단가 계산기 (`avg.html`)

여러 번 나눠 산 매수 내역(가격·수량)을 입력하면 아래를 계산합니다.

- 평균 매입단가, 보유 수량, 총 매입금액
- 현재가 기준 평가금액·평가손익·수익률, 본전까지 필요한 상승률
- 추가 매수 시뮬레이션: 수량을 넣으면 새 평단가, 목표 평단가를 넣으면 필요한 수량(물타기·불타기)

수수료·세금은 반영하지 않습니다. 입력값은 그 브라우저에만 저장됩니다.
